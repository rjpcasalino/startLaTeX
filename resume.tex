    \begin{itemize}[leftmargin=1.2em, itemsep=0.25em]
            \item[] Interfaces directly with \texttt{mpv} as a backend media player, utilizing JSON IPC sockets (\texttt{/tmp/am\_radio\_\$\$\_.sock}) for asynchronous process control, track polling, and status management.
            \item[] Integrates with the Radio-Browser.info API via \texttt{curl} for global stream searching and leverages \texttt{ffprobe} to dump stream codecs and bitrates.
            \item[] ``Old Time Radio'' audio filter injecting a \texttt{libavfilter} chain (\texttt{highpass=f=300,lowpass=f=4500,acompressor}) to emulate compressed vintage AM sound.
            \item[] TUI mode with preset navigation, live tuning, and automated terminal resizing.
    \end{itemize}

    \item \textbf{bss (Boring Static Site Generator)}: A minimalist static site generator written in Perl that pairs Template Toolkit with \texttt{rsync} for rapid page generation and asset synchronization.
    \begin{itemize}[leftmargin=1.2em, itemsep=0.25em]
            \item[] An LLM (I cannot remember what model at this point) used a hash map or "pre-scanned template lookup cache'' (\texttt{\%template\_map}), optimizing buildtime from $O(n \times m)$ complexity down to $O(n + m).
            \item[] Features a built-in HTTP server coupled with a detached background file watcher (\texttt{setsid()}, \texttt{fork()}, and file modification time scanning) that triggers incremental builds upon changes.
            \item[] Automatically compiles and writes a JSON metadata file (\texttt{\_\_bss\_meta.json}) tracking build IDs, timestamps, build duration in milliseconds, page/file counts, and total payload size.
            \item[] Driven via a \texttt{manifest.ini} configuration file supporting YAML front-matter parsing, Markdown conversion via \texttt{Text::Markdown}, content collections, and customizable exclusion rules.
    \end{itemize}
